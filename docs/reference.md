## Команды

| Команда | Что делает |
|---|---|
| `init [--locale ru]` | Создаёт `.uichanges/` с конфигом |
| `capture` | Снимает слепки всех страниц из конфига. Первый раз — базовые, дальше — текущие для сравнения |
| `review [--port 4400]` | Режим описания на сайте: подсветка изменений и панель |
| `status` | Изменения в консоли и какие из них ещё не описаны |
| `describe <id> [--force]` | Создаёт файл описания из шаблона |
| `ignore <id>` | Помечает изменение как «не показывать пользователям» |
| `accept` | Текущие слепки становятся базовыми |
| `check` | Для CI: код выхода 1, если есть неописанные изменения |
| `build [-o файл]` | Собирает описания в манифест для сайта. `review` делает это сам при каждом сохранении |
| `snapshot <адрес\|файл>` | Слепок одной страницы в JSON |
| `diff <до.json> <после.json>` | Сравнение двух слепков |

Флаги для команд, которые снимают слепки: `--storage-state <файл>`, `--wait-for <селектор>`, `--delay <мс>`, `--ignore <селектор>`, `--width <px>`.

## Настройки: .uichanges/config.json

```json
{
  "screens": [
    { "name": "home", "url": "http://localhost:5080/" },
    { "name": "catalog", "url": "http://localhost:5080/catalog", "waitFor": ".product-card" }
  ],
  "widths": [1280],
  "storageState": "auth.json",
  "ignore": [".recommendations"],
  "dynamic": [],
  "locale": "ru",
  "manifest": "wwwroot/uichanges.json"
}
```

| Поле | Что значит |
|---|---|
| `screens` | Страницы. `name` — имя файла слепка, `url` — адрес. Необязательные поля: `path` (путь, на котором показывать подсказки, если он отличается от пути в `url`), `waitFor` (ждать появления элемента), `delay` (подождать N мс), `ignore` (селекторы только для этой страницы) |
| `widths` | Ширины окна. Слепки разной ширины никогда не сравниваются: кнопка в бургер-меню на телефоне — это адаптация, а не изменение |
| `storageState` | Файл сессии Playwright для страниц за логином |
| `ignore` | CSS-селекторы частей страницы, которые uichanges не смотрит |
| `dynamic` | Элементы, текст которых — данные пользователя. Заполняется кнопкой «Это данные пользователя» в режиме описания |
| `locale` | Язык шаблонов описаний и панели |
| `manifest` | Куда собирать манифест. Это должна быть папка, откуда сайт отдаёт статические файлы |

В git хранятся `config.json`, `snapshots/` (базовые слепки), `changes/` (описания) и `ignored.json`. Папка `current/` не коммитится.

## Режим описания

`uichanges review` запускает маленький сервер на `127.0.0.1:4400` и печатает ссылки на ваши страницы вида `http://localhost:5080/?uichanges=review&uichanges-port=4400&uichanges-token=…`.

На странице, открытой по такой ссылке, скрипт uichanges не показывает подсказки, а загружает панель:

- изменённые элементы обведены: зелёным новые, синим переехавшие, оранжевым переименованные;
- в панели список изменений: на этой странице, без элемента (удалённые) и на других страницах;
- «Обновить слепки» снимает текущую версию сайта, «Принять как базу» делает её точкой отсчёта;
- описание сохраняется в `.uichanges/changes/<id>.md`, манифест пересобирается сразу.

Режим действует в этой вкладке, пока вы её не закроете. Выйти — кнопка «Выйти» в панели или адрес с `?uichanges=off`. Токен из адреса сразу убирается.

Безопасность: сервер слушает только `127.0.0.1` и принимает запросы только с токеном, который напечатан в терминале. Другой сайт, открытый в браузере, не может ничего записать в ваш проект.

Ограничение браузера: страница должна открываться с вашей машины (`localhost`, `127.0.0.1`). Если открыть по ссылке тестовый сервер в сети, Chrome спросит разрешение на доступ к локальной сети.

## Файлы описаний

Обычный Markdown. Строка `---` разделяет слайды. Шапку между первыми `---` заполняет uichanges, обычно её не трогают.

```markdown
---
id: button-sravnit-tovary
type: added
path: /
priority: high
locators: ["role=button[name=\"Сравнить товары\"]"]
---

# Новое: сравнение товаров

Выбирайте между похожими товарами, не открывая десять вкладок.

---

## Как пользоваться

1. Отметьте **2–4 товара** в каталоге
2. Нажмите «Сравнить товары»
```

- `priority`: `high`, `normal` или `low`; важные показываются первыми.
- Перевод — файл рядом: `button-sravnit-tovary.en.md`. Скрипт выбирает язык по `<html lang>`.
- Можно: заголовки, списки, **жирный**, *курсив*, `код`, ссылки, картинки. Сырой HTML экранируется, ссылки `javascript:` отбрасываются.
- `![](auto:before-after)` — автоматические скриншоты, пока не реализованы и пропускаются с предупреждением.

## Скрипт на сайте

Без сборщика:

```html
<script src="https://unpkg.com/uichanges/dist/uichanges.js" data-manifest="/uichanges.json" defer></script>
```

Атрибуты: `data-locale="ru"`, `data-auto-open` (открыть первую подсказку сразу), `data-show-on-first-visit` (показывать и новым пользователям). Для надёжности можно закрепить версию в адресе (`uichanges@0.2.0`) или скопировать файл к себе.

Со сборщиком:

```js
import { uichanges } from 'uichanges/runtime';

uichanges.start({
  manifest: '/uichanges.json',
  locale: 'ru',
  maxBeacons: 3,          // сколько точек показывать одновременно
  autoOpen: false,
  showOnFirstVisit: false,
  storage: myStorage,     // { get(key), set(key, value), remove(key) } — например, синхронизация через ваш API
  onShow(change) {},
  onDismiss(change) {},
});

uichanges.open('link-korzina'); // открыть подсказку из кода
uichanges.reset();              // забыть просмотренное
uichanges.stop();               // убрать всё со страницы
```

Скрипт весит около 8 KB в gzip, не имеет зависимостей и рисует всё в Shadow DOM. Цвета: CSS-переменные `--uic-accent`, `--uic-bg`, `--uic-text`. Просмотренное хранится в `localStorage` под ключом `uichanges:seen`. Если элемент не найден, подсказка не показывается. Элементы, которые появляются или перерисовываются позже (SPA, Blazor), подхватываются автоматически.

## Как сопоставляются элементы

Слепок — это список видимых кнопок, ссылок, полей и заголовков с ролью, доступным именем, ориентирами страницы (шапка, меню, основная часть) и координатами.

Пары «было — стало» ищутся в три прохода, от самого надёжного признака к самому слабому:

1. явные ключи `data-uichanges`, затем `data-testid`;
2. роль + имя, если такая пара на странице одна;
3. похожесть по роли, имени, ориентирам и положению, в том числе относительно соседей: кнопка, переехавшая вместе со своим разделом, находится, даже если её переименовали.

Затем:

- **переехал**: сменился ориентир или элемент сдвинулся больше чем на 120 px (за вычетом общего сдвига области, например если шапка стала выше);
- **переименован**: сменилось имя, если это не данные пользователя;
- **новый** и **удалён**: элементы без пары;
- элементы, сдвинувшиеся вместе, объединяются в **блок** и описываются одним текстом.

Сомнительные пары помечаются «проверьте».

## Атрибуты в разметке

| Атрибут | Зачем |
|---|---|
| `data-uichanges="id"` | Постоянное имя элемента: uichanges узнает его, как бы его ни переделали |
| `data-uichanges-ignore` | Часть страницы, на которую uichanges не смотрит |
| `data-uichanges-dynamic` | Текст элемента — данные пользователя, его смена не изменение |

## Blazor

Скрипт подключается в `App.razor` (Blazor Web App / Server) или `wwwroot/index.html` (WebAssembly), манифест кладётся в `wwwroot`: `"manifest": "wwwroot/uichanges.json"`. Атрибуты пишутся прямо в Razor. Если сайт открыт по https, режим описания всё равно работает: браузеры разрешают обращения к `127.0.0.1`.

## CI

```yaml
- run: npx uichanges capture   # сайт должен быть запущен
- run: npx uichanges check     # упадёт, если есть неописанные изменения
```
